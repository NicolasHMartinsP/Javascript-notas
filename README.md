# Registros e exercicios em JS | TS

---

### Resumo

| **Variáveis e Tipos**<br>- `const`, `let` ou `var`?<br>- Quais os tipos primitivos?<br>- Valor x referência | - `const` por padrão, `let` se o valor muda, `var` evitar.<br>- `string`, `number`, `boolean`, `undefined`, `null` (+ `bigint`, `symbol`). `typeof` descobre o tipo.<br>- Primitivos são copiados; arrays e objetos apontam para o mesmo lugar (copiar com `[...a]` / `{...o}`). |
| ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Operadores e Math**<br>- Aritméticos e comparação<br>- Lógicos<br>- Math                                  | - `+ - * / ** %`, `++`, `+=`. Usar `===` e `!==` (comparam valor e tipo).<br>- `&&` (E), `\|\|` (OU), `!` (NÃO); `??` só troca `null`/`undefined`.<br>- `Math.floor`, `ceil`, `round`, `random`, `max`, `min`; `toFixed(2)` devolve string.                                      |
| **Strings**<br>- Principais métodos?<br>- São mutáveis?                                                     | - `length`, `indexOf`, `includes`, `slice`, `split`/`join`, `trim`, `toUpperCase`, `replaceAll`, `padStart`.<br>- Não: todo método devolve uma string nova.                                                                                                                      |
| **Controle de Fluxo**<br>- Decisão<br>- Repetição                                                           | - `if / else if / else`, ternário `cond ? a : b`, `switch` com `break`.<br>- `for`, `while`, `do...while`, `for...of` (valores), `for...in` (chaves), `break` e `continue`.                                                                                                      |
| **Arrays**<br>- Adicionar e remover<br>- Métodos de alto nível                                              | - `push`/`pop` (fim), `unshift`/`shift` (começo), `splice`; `slice` copia.<br>- `map` (transforma), `filter` (seleciona), `reduce` (acumula), `find`, `sort((a, b) => a - b)`.                                                                                                   |
| **Objetos**<br>- Acesso<br>- Métodos e `this`<br>- Utilitários                                              | - `obj.chave` ou `obj["chave"]`; desestruturação `const { nome } = obj`.<br>- `this` é o objeto que chamou o método.<br>- `Object.keys/values/entries`, spread, `?.`, `JSON.stringify/parse`.                                                                                    |
| **Funções**<br>- Formas de declarar<br>- Conceitos importantes                                              | - `function nome() {}`, anônima em variável, arrow `(n) => n * 2`.<br>- Parâmetro padrão, rest `...args`, callback, closure (lembra do escopo onde nasceu) e recursão (precisa de caso base).                                                                                    |
| **DOM**<br>- Selecionar e alterar<br>- Eventos                                                              | - `getElementById`, `querySelector(All)`, `textContent`, `classList`, `createElement`, `append`.<br>- `addEventListener`, `preventDefault` no submit, delegação com `closest`.                                                                                                   |
